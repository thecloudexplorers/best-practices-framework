# Architecture Templates

This folder contains templates for architecture documents. Use these templates as a basis or a
reference in case you need to create or update architecture documentation for your projects.

The templates are:

- [Technical Design Document](technical-design.md) - Combines high-level and low-level design into a
singledocument. This is the recommended template for most scenarios.
- [High Level Design Document - Soon](high-level-design.md) - Describes the overall solution
- [Low Level Design Document - Soon](low-level-design.md) - Provides detailed design information on
an implementation level.
